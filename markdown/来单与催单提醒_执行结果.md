## 用户验收步骤

1. 在 IDEA 重新编译并重启后端。
2. 刷新 Nginx 管理端，右下角应出现“开启语音提醒”；点击一次开启。若浏览器保留旧页面，执行强制刷新。
3. 重新编译小程序，完成一次模拟支付，管理端应出现“待接单”弹窗与来单提示音。
4. 对已支付且仍在处理的本人订单点击催单，管理端应出现“催单”弹窗与催单提示音。
5. 未付款、已完成、已取消等订单不能催单；失败应正常提示，不应卡死按钮或假提示成功。

管理端源码的跨部署文件一致性测试可以通过环境变量 `SKY_ADMIN_DEPLOYED_ROOT` 指定 Nginx 的 `html\sky` 目录，再用 Node 执行 `tests\order-notifications.test.cjs`。本次执行指向工作副本，不改业务页面运行状态。
